# MediaDown

**A Modern Universal Video Downloader for Windows**

MediaDown is a modern desktop application designed to download videos from supported social media platforms through their URLs.

### Features
- Multi-platform video downloading
- Batch URL downloading
- Download queue management
- Download history
- Video thumbnail saving
- Automatic file naming
- MP4 and MP3 support
- Up to 4K quality selection
- Multiple interface languages
- Customizable application settings
- Modern Windows interface

### Supported Platforms
- YouTube
- TikTok
- Instagram
- X (Twitter)
- Facebook
- Other yt-dlp supported platforms
